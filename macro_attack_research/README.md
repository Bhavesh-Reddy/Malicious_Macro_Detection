# NIDS Infiltration Detection System
**Execution and Deployment Guide (Deliverable 16)**

This repository contains a complete, leakage-free Machine Learning pipeline designed to detect Network Infiltration attacks (macro-based breaches) using the CSE-CIC-IDS2018 and CIC-IDS2017 datasets.

## 1. Prerequisites & Environment Setup

Ensure you are running a Python 3.10+ environment (Linux recommended).

Install the required dependencies:
```bash
pip install pandas numpy scikit-learn lightgbm xgboost pyarrow fastparquet
```

## 2. Directory Structure

Your project should be structured as follows:
```text
macro_attack_research/
├── data/
│   ├── dataset_a_2018/      # CIC-IDS-2018 CSVs
│   └── dataset_b_2017/      # CIC-IDS-2017 CSV

│   ├── phase7_online_learning.py
│   ├── realtime_adapter.py
│   └── attack_emulation.py
├── Final_Technical_Report.md
└── README.md
```

## 3. Pipeline Execution Guide

Run the pipeline sequentially from the `macro_attack_research` directory. Do not skip steps, as each phase relies on the artifacts (like medians and models) generated by the previous phase.

### Phase 1: Data Cleaning & Sanitization
* **Purpose:** Strips headers, canonicalizes column names, and scans for NaN/Inf.
* **Execution:** `python3 src/phase1_cleaning.py`

### Phase 2: Chronological Partitioning
* **Purpose:** Performs a strict temporal 70/10/20 split to prevent leakage.
* **Execution:** `python3 src/phase2_partition.py`

### Phase 3: Model Optimization
* **Purpose:** Trains Random Forest, LightGBM, and XGBoost models. Generates classification reports.
* **Execution:** `python3 src/phase3_model.py`

### Phase 4: Zero-Trust Generalization (OOD)
* **Purpose:** Validates models against the unseen 2017 dataset to measure domain drift.
* **Execution:** `python3 src/phase4_ood.py`

### Phase 5: Ablation Study
* **Purpose:** Systematically tests the removal of features, balancing, and temporal splits.
* **Execution:** `python3 src/phase5_ablation.py`

### Phase 6: Real-Time Inference Adapter
* **Purpose:** Simulates a live production network stream to calculate model latency and throughput.
* **Execution:** `python3 src/realtime_adapter.py`

### Phase 7: Continuous Online Retraining
* **Purpose:** Simulates micro-batch online learning to solve the concept drift bottleneck identified in Phase 4.
* **Execution:** `python3 src/phase7_online_learning.py`

## 4. Attack Emulation

To test the generation of malicious network traffic signatures (simulating a macro-based payload download and C2 beaconing), run:
```bash
python3 src/attack_emulation.py --target 8.8.8.8 --port 443
```
